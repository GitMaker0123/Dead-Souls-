CORREÇÕES E MÚSICA
- Corrigida a origem do problema das vozes: os MP3s de dano da 1.1.2 estavam silenciosos.

  musica-menu.ogg       — menus, saves, criação de personagem e pausa

  musica-chefe.ogg      — durante confrontos com chefes

ATUALIZAR NO GITHUB
1. Extraia este ZIP no celular.
2. No seu repositório Dead-Souls-, branch main, envie os ARQUIVOS diretamente na raiz.
3. Substitua os arquivos existentes e inclua os três novos musica-*.ogg.
4. Faça Commit changes.
5. Abra o site com internet e recarregue. O service worker foi atualizado.
6. Não limpe os dados do site: os saves ficam no armazenamento do navegador.

OBS.: O navegador pode exigir uma interação do usuário para permitir áudio. A reprodução no Android e a transição entre músicas devem ser testadas no dispositivo físico.
