Som e interface

Configure os efeitos sonoros para combinar com seu estilo de jogo.

Combate

Celular: use o analógico, ATACAR, FORTE, ESQUIVA, CURAR e INTERAGIR.

PC: WASD ou setas, J/espaço para atacar, L para golpe forte, Shift/K para esquivar, H/Q para curar, E para interagir e Esc para pausar. Gamepad: analógico esquerdo, R1/RB ataque normal, R2/RT ataque forte lento, A/Cruz interagir, X/Quadrado curar, B/Círculo esquivar, Start pausar.

Esquiva garante invulnerabilidade durante o impulso. A cada quinta sala surge um chefe aleatório. O vigor se recupera sozinho; cada sala termina quando a passagem ao norte é liberada. Use E para interagir e H para curar.

Salas e chefes

Uma única área com salas: Pátio Externo. A cada 5 salas um dos nove chefes é sorteado, com padrões próprios de ataques e avisos visuais.

Os chefes são interpretações originais simplificadas para esta beta; não utilizam imagens ou arquivos de outros jogos.

Salvamento

Fogueiras são elementos do cenário. Aproxime-se e toque em INTERAGIR para recuperar vida, vigor, restaurar as 3 curas e salvar. Ao limpar a sala, siga pelo portão norte.

Até 3 perfis salvos neste navegador. Os dados ficam no dispositivo: não sincronizam entre celulares.
